# \# PHANTOM FM

# 

# \*\*The Signal Never Dies.\*\*

# 

# PHANTOM FM is a retro-futuristic pirate broadcast project built around a haunted computer / underground media network aesthetic.

# 

# The site is designed like a fictional operating system where users can access live TV, radio, IRC chat, and archive-style pages through one unified PHANTOM OS interface.

# \### PHANTOM TV

# 

# A custom live TV interface connected to the PHANTOM FM IPTV backend.

# 

# Features:

# 

# \- HLS video playback

# \- Channel switching

# \- XMLTV guide support

# \- Custom PHANTOM-styled guide drawer

# \- Live signal/status display

# \- Retro broadcast interface

# 

# Current channels include:

# 

# \- Adult Swim

# \- How It's Made

# \- Force TV

# \- Null/offline test channel

# 

# \### PHANTOM RADIO

# 

# A custom PHANTOM RADIO page using an embedded YouTube carrier as a placeholder source.

# 

# Features:

# 

# \- YouTube source monitor

# \- Custom play/pause controls

# \- Volume control

# \- Animated visualizer effect

# \- PHANTOM-style radio interface

# 

# The current visualizer is a simulated PHANTOM-side effect. It does not rip, extract, or analyze YouTube audio directly.
